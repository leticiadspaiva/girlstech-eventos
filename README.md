# 🌸 Girls Tech - Calendário de Eventos de Tecnologia no Brasil (2026)

Bem-vindo(a) ao repositório do **Girls Tech**, uma Single Page Application (SPA) desenvolvida para mapear e organizar os principais eventos de tecnologia, universidades e multinacionais acontecendo em todos os estados do Brasil até o final do ano de 2026.

## 🎯 O Projeto
A plataforma visa facilitar o acesso à informação sobre eventos tecnológicos (gratuitos e pagos, incluindo eventos do LinkedIn e de grandes instituições), centralizando tudo em um mapa/grid interativo e intuitivo focado na usabilidade.

## 🚀 Funcionalidades
- **Autenticação Simples:** Tela de login padrão para controle de acesso.
- **Navegação por Região/Estado:** Eventos categorizados geograficamente (Norte, Nordeste, Centro-Oeste, Sudeste e Sul).
- **Redirecionamento Direto:** Links externos para as páginas de inscrição oficiais dos eventos.
- **Design Responsivo:** Interface fluida que se adapta perfeitamente a dispositivos móveis e desktops.

## 🎨 UI/UX e Paleta de Cores
O design foi construído em torno de uma identidade visual forte e acolhedora, baseada na logomarca oficial, utilizando a seguinte paleta de cores:
- **Primary:** `#D84272` (Rosa Escuro/Magenta)
- **Secondary:** `#FDBFD6` (Rosa Claro)
- **Cream:** `#FFF1E8` (Fundo Principal)
- **Dark:** `#953352` (Textos e Destaques)
- **Soft:** `#F4F2E5` (Elementos Secundários)

As tipografias escolhidas (`Pacifico` para destaques e `Poppins` para leitura) garantem uma leitura agradável e um visual moderno.

## 🔐 Acesso para Demonstração

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica.
- **CSS3 / Tailwind CSS:** Estilização via classes utilitárias para um desenvolvimento ágil e responsivo.
- **JavaScript (Vanilla):** Lógica de autenticação, manipulação do DOM e renderização dinâmica dos dados.
